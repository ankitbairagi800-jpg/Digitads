# Digitalads Next.js Application

This is the production-grade, highly optimized **Next.js 15+ App Router** implementation for Digitalads (`thedigitalads.in`).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Development Tasks

- **Development Server**: `npm run dev` starts the local dev server.
- **Production Build**: `npm run build` compiles and generates optimized static files.
- **Static Output**: Pre-rendered static pages will be stored under `.next` and optimized for fast CDN delivery.

## Features

- **Modern Architecture**: Built using Next.js 15+ App Router, React 19, and Tailwind CSS.
- **SEO Ready**: Standardized metadata, structured schema integration, dynamic SEO sitemap, and Google/Bing-friendly `robots.txt` are configured out-of-the-box.
- **Responsive Layout**: Stunning premium Earthy Luxury aesthetic with smooth fluid animations and 100% mobile-first design.
